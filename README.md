# sok-i-vilkar
## Bakgrunn
Mye rådgivertid går til å svare på spørsmål rundt dekninger/vilkår. Per i dag så må rådgiver navigere til infokanalen, finne riktig avsnitt og deretter finne/søke i det relevante vilkårsdokumentet. Tanken er å lage en proof-of-concept app som samler alle dokumenter på ett og samme sted - for å gjøre søk i vilkår enklere og spare tid. Prosjektet vil også fungere som en platform for egen læring - utforske nye teknologier og valg rundt funksjonalitet/design. 

En logg over arbeidet finner du [her](./LOG.md). <br>
Appen er deployed på render.com og kan brukes [her](https://sok-i-vilkar.onrender.com/).



## Tech
Front - React / Typescript (Vite)<br>
Back - Node.js / Express
